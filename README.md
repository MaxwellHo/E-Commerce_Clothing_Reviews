E-Commerce Clothing Review Return and Quality Analysis

Goal: This project aims to present data driven analysis on e-commerce clothing based on negative reviews (2 stars or less), uncovering the reasoning and frequency behind those complaints about a product. Looking into various metrics included total return cost (operational cost + refunded sales) by type of clothing, defective clothing volume and severity, sizing failure by garment class, primary return causes, etc. This analysis can help understand which clothing experience the most returns, cause of return, return loss leaders, and the severity of the defective product. Leveraging these data driven insights enables companies to significantly lower return loss, improve product quality, and boost customer satisfaction to drive long term brand loyalty.


Dataset: https://www.kaggle.com/datasets/nicapotato/womens-ecommerce-clothing-reviews
